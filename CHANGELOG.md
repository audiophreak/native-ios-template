# Changelog

Versions are git tags (`vMAJOR.MINOR.PATCH`). In 0.x, a minor bump may be breaking.

## 0.1.0

First release. The native iOS layer for `web-core-template` 0.7.x (`auth` + `native_client`).

- `ios/`: a SwiftUI app (Swift 6, iOS 17.0 minimum) with a static Xcode project (synchronized folders; settings in
  `Config/*.xcconfig`, no team or signing material), a local Swift package `AppCore` and hosted tests.
- **Typed API client** generated by `swift-openapi-generator` 1.14.3 from `ios/Contract/openapi.json` (the web 0.7.0
  contract), with `swift-openapi-runtime` 1.13.4 and `swift-openapi-urlsession` 1.4.0 (exact pins, resolved state
  committed, ages and licences in `docs/dependencies.md`). The generated code is committed; CI regenerates it and requires
  zero difference.
- **Authentication:** Better Auth's bearer token (`set-auth-token` of sign-in), kept in the Keychain
  (`kSecAttrAccessibleWhenUnlockedThisDeviceOnly`, never synchronised); `BearerAuthMiddleware` adds it to API requests only
  for the configured origin, ends the session on a confirmed 401 and adopts a rotated token. The password is never stored.
- **Transport:** Release https only with no App Transport Security exception; Debug `NSAllowsLocalNetworking` only; no
  certificate pinning, no validation override, no redirects followed, no cookies.
- Tests: 58 package tests (problem details, configuration, auth state, middleware, auth service, API service including
  malformed and unexpected answers, models, contract compatibility, a whole-scenario test against a stand-in server) and
  hosted tests (Keychain, build configuration, wiring, the real end-to-end scenario driven by `ios/scripts/e2e.mjs`).
- Layering: separate answers file `.copier-answers.ios.yml`; the layer never writes a web file.
